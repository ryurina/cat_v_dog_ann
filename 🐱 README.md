# 🐱 Cat vs Dog ANN

A cat vs dog image classifier built **completely from scratch using NumPy**, without PyTorch, Keras, or TensorFlow. The model is served through a Streamlit web application.

## 🚀 Live Demo

[Try the Cat vs Dog classifier](https://catvsdog-7xx7.onrender.com/)

## 📦 Requirements

- Python 3.x
- Streamlit
- NumPy
- Pillow
- h5py
- Matplotlib
- Scikit-learn
- tqdm

## ⚙️ Installation

```bash
git clone https://github.com/ryurina/cat_v_dog_ann.git
cd cat_v_dog_ann
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
